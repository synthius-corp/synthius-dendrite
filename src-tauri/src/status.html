Telegram snapshot

Choose a persona here, then sign in to Telegram in Dendrite’s secure window. Select conversations and dates to save their history as local source files.

Each snapshot uses a fresh login. Telegram authorization tokens are used once in memory on this computer, then discarded for maximum security. Dendrite saves no authorization tokens to disk or Cloud storage. Finish or pause attempts logout and discards the session. This is Dendrite’s maximum-security approach to one-time Telegram snapshots.

Dendrite adds each completed snapshot to Local Sources automatically. When the download finishes, follow the persona link and choose Process new info in Synthius when you want to add it to memory.
